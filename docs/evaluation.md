# 评价协议草案

## 主张范围

“成功率 >95%”只对预先声明的任务分布、环境、预算和成功定义成立。先区分真实机器人、在线仿真执行和离线搜索实验，分别报告；不能用子世界中的成功替代执行世界的成功。

## 固定实验条件

运行前冻结任务清单、TRAIN/验证/测试划分、场景、物体、随机种子、模型与资产版本、引擎版本、硬件、动作频率、单回合时间上限、rollout 数量及允许重试次数。评测集不得用于调阈值。

每个测试回合都进入主结果分母。超时、感知失败、无可行轨迹、抓取失败、释放失败和无法恢复的执行错误均记失败。若预先规定基础设施异常可作废，需要单独列出原始记录、作废原因和重跑结果，不能静默排除。

## 指标

- **端到端成功率：** 成功回合数 / 全部有效测试回合数。报告原始整数和 95% Wilson 置信区间。
- **首次成功率与预算内成功率：** 分别报告，避免用无限重试掩盖失败。
- **任务分层表现：** 同时报任务、场景、物体类别的成功率及总体 micro / macro 平均。
- **仿真—执行差距：** 报告仿真通过且真正执行的候选数，以及其中执行失败数。
- **成本：** 在线延迟中位数/P95、每回合 rollout 数、GPU 时间、重建次数和执行重试次数。
- **稳定性：** 报告跨种子波动、标定偏差、遮挡和参数扰动下的表现。

观测成功率超过 95% 与“有统计支持地超过 95%”是不同声明。后者在本协议中要求预先固定样本规模、成功率 95% 双侧 Wilson 区间下界超过 0.95，并满足事先声明的任务覆盖要求。重复直到达标会引入偏差，不能作为固定样本评测。

## 对照与消融

保持任务、执行预算与信息权限一致，对比：训练轨迹直接跟随、单世界搜索、多世界搜索，以及多世界搜索加在线重新对齐。另行改变世界数量、位姿假设数量、搜索预算和重规划频率，报告成功率与成本的变化。
