以可交互的世界，支持持续改进的动作策略。

资料
GitHub / 系统架构 / 评价协议

我们提出将仿真作为 GPT Agent 的物理交互世界。Agent 从 TRAIN 参考与在线 RGB-D 构建场景，在仿真中探索动作，再通过执行反馈改进下一次决策。

方法

01

Interactive World Simulator

TRAIN 观测为交互资产提供参考，RGB-D 与机器人状态确定当前场景中的物体、接触区域和障碍。实际观测到的接触与运动，用于修正几何、位姿和物理参数。

02

Self-Evolving Policy

Agent 在独立仿真分支中探索候选动作程序，修复失败尝试，并对成功轨迹评分。选中的程序通过完整子任务验证后交给执行世界跟随。新观测用于重新对齐场景，并改进动作程序、技能和搜索过程。

一个例子：包裹分拣

在 RoboColiseum 的 sorting_packages 任务中，机器人抓起包裹，放到扫描台，再次抓取，最后松手入筐。TRAIN 86 提供前三段动作参考，TRAIN 30 提供后三段。

开发结果

一次已记录的单包仿真回合在 1,200 个控制步内完成全部六个阶段，原生 E2E = 1。后续将扩展并行搜索与策略进化机制。
