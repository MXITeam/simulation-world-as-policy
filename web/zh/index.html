GitHub / 系统架构 / 评价协议

从头部 RGB-D 重建最小仿真孪生，保留任务相关几何与简单表面材质。单臂机器人在大量孪生副本中并行试错，将成功抓取点与轨迹总结为可复用 skill，将重建物体与物理参数沉淀为资产。后续轮次复用资产与技能，执行反馈继续推动重建和搜索进化。

方法

01

Interactive World Simulator

TRAIN 观测为交互资产提供参考，RGB-D 与机器人状态确定当前场景中的物体、接触区域和障碍。实际观测到的接触与运动，用于修正几何、位姿和物理参数。

02

Self-Evolving Policy

Agent 在独立仿真分支中探索候选动作程序，修复失败尝试，并对成功轨迹评分。选中的程序通过完整子任务验证后交给执行世界跟随。新观测用于重新对齐场景，并改进动作程序、技能和搜索过程。
