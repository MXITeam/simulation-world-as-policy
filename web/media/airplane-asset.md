# Airplane diagram asset

The SVG is an oblique projection of `train_scene_rgbd_20261105/w2/airplane_rgbd_full_sequence.ply`, the reconstructed airplane from the RoboColiseum TRAIN episode 301 development experiment. It preserves the mesh geometry and uses gray-blue face shading for the black website. This is a reconstructed mesh, rather than the original CAD asset. The same SVG is reused throughout the animated method diagram.
