Simulation World as Policy

An interactive world for an evolving action policy.

Status
Method proposal & development case
Resources
GitHub / Design note (中文) / Evaluation protocol (中文)

Reconstruct a minimal simulation twin from head-view RGB-D, retaining task-relevant geometry and simple surface materials. A single-arm robot try candidate actions in parallel copies of the twin. Successful grasps and trajectories become reusable skills, while reconstructed objects and physical parameters enter an asset library. Each new round reuses these assets and skills, and execution feedback refines the next search.

Method

01

Interactive World Simulator

TRAIN observations provide references for interaction assets. RGB-D and robot state ground the objects, contact regions, and obstacles in the current scene. Observed contact and motion guide updates to geometry, pose, and physical parameters.

02

Self-Evolving Policy

The agent explores candidate action programs in independent simulation branches, repairs failed trials, and ranks successful trajectories. Selected programs undergo complete subtask validation before execution. New observations realign the scene and inform updates to action programs, skills, and search procedures.

A case study: package sorting

In RoboColiseum’s sorting_packages task, the robot picks up a package, places it on a scanner, grasps it again, and releases it into a bin. TRAIN 86 supplies the first three action references; TRAIN 30 supplies the remaining three.

Development result

One recorded single-package simulation episode completed all six stages in 1,200 control steps, with native E2E = 1. Parallel search and policy evolution are planned extensions.
