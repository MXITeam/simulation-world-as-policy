# Research website

English: `index.html`. Chinese: `zh/index.html`.

Run `python3 -m http.server 18766 --bind 127.0.0.1` from the repository root.

The black website uses HTML, SVG, CSS and JavaScript. Its interactive diagram supports four assets and six visible robot joints. Two article sections introduce modeling and a successful RoboColiseum shelf-stocking episode, each followed by a large video with playback controls. Video provenance is documented in [media/videos/README.md](media/videos/README.md).
